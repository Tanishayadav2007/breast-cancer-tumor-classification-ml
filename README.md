# Breast Cancer Tumor Classification (ML Project)

## 📌 Overview
This project predicts whether a tumor is **benign or malignant** using machine learning models trained on the Breast Cancer dataset.

## 🚀 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📊 Models Used
- Logistic Regression
- Random Forest

## 📈 Results
- Achieved **97% accuracy**
- Evaluated using:
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix

## 🔍 Workflow
1. Data preprocessing
2. Feature selection
3. Model training
4. Model evaluation
